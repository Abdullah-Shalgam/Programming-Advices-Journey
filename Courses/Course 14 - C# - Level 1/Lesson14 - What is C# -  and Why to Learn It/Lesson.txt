 🚀C#: General purpose , OOP without Functional Programming.

 🌟C# is one of the most popular languages for building desktop and web applications on the .NET platform.
 🌟C# is influenced by C and C++ and is syntactically similar to Java.
 🌟so that is why you can learn the basic syntax of C# quickly if you already know C++.
 🌟C# is a modern language introduced in 2002 and continuously evolving ( C# 11 in 2022), and it enables rapid application development using .NET libraries and tools..
🌟C# ensures that each variable has its particular type.
🌟C# supports OOP paradigm such as objects, classes, inheritance, polymorphism, etc..
🌟C# is a high-level language that abstracts low-level details, making it easier to read and write
🌟C# has huge Community.
