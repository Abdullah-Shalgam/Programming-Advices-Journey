✨The Summary✨

🔥 .NET : is a platform that supports languages like C#, Visual Basic, and F# that are compiled to IL (Intermediate Language)
🎯 in runtime using CLR (Common Language Runtime) which executes code, manages memory via Garbage Collection, and handles exceptions(errors).
💥 provides  BCL (Base class libraries) to work with files, networking, and databases.
👉 يعني:

🔥 الخلاصة السريعة:
.NET = Platform
CLR = بيشغّل الكود + يدير الميموري + الأخطاء
BCL = مكتبات جاهزة تختصر عليك الشغل

💡 Platforms
👉 .NET Core (new): cross platform run anywhere (windows, linux,...).
👉 .NET Framework (old): websites, services, desktop apps but for windows only
👉 Xamarin/Mono: for mobile applications like Flutter.

😏all use a standard set of libraries.

🔥 الخلاصة اللي تثبّت الدنيا:
.NET Framework → قديم + Windows فقط
.NET Core → بداية التطوير الجديد
Xamarin/Mono → موبايل
.NET الحديث (5+) → دمج كل ده في حاجة واحدة
