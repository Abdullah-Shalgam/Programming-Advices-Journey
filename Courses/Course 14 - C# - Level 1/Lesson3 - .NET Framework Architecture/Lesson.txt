.Net Framework: Implementation of the platform
.NET Framework = تطبيق من التطبيقات دي (قديم + Windows)

Two Major Components:

🟩 1 CLR (Common Language Runtime) -Brain🧠-
Handles running applications and provides services like Garbage Collection , handling errors and JIT Compiler.

🟦 2 BCL (Base class libraries)
Set of APIs and common functions: for reading and writing files, networking, databases, drawing
